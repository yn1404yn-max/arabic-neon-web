# أداة نصوص النيون واللافتات الاحترافية 🌟
### Comprehensive Arabic Neon & LED Signboard Generator

أداة ويب تفاعلية متطورة وخفيفة الحجم تعمل فور فتح الصفحة، متخصصة في تصميم وتحريك نصوص الخطوط العربية بتأثيرات النيون الواقعية (Neon Glow) ولافتات شاشات الـ LED مع حزمة شاملة تضم **40 خطاً عربياً**، **30 إطاراً للافتات الليد**، **30 نمط وميض**، و**30 حركة نصية متقدمة**، مع دعم كامل للغة العربية (RTL) والحركات، وحفظ وتصدير بعدة صيغ (PNG بدقة عالية، SVG، كود CSS نقي، وفيديو WebM).

### 4. 🎬 الحركات النصية المتقدمة (30 حركة نصية)
- **مجموعة الدخول والظهور:** ظهور تدريجي ناعم، انزلاق لليمين، انزلاق لليسار، صعود، هبوط، تكبير، تصغير، دخول ارتدادي مرن، قلب أفقي 3D، قلب عمودي 3D.
- **مجموعة الحركة والدوران:** دوران دائري (Spin)، تأرجح معلق، موجة رأسية، ميل وانحراف، مطاطي (Rubber Band)، تأثير هلامي (Jello)، خفقان نصي، لفت انتباه سريع، لمعان داخلي (Shimmer)، انزلاق مع تقطيع.
- **مجموعة التأثيرات الإبداعية والسينمائية:** آلة كاتبة (Typewriter)، تساقط مصفوفة (Matrix Rain)، طفو ونجيع، جذب وانكماش، تموج أفقي، دوامة مركزية (Vortex)، نبض متموج السطح، ظهور بفرقعة مرنة، كشف ضبابي تدريجي، رقصة موجية لا نهائية للأحرف.

### 5. 🎨 ثيمات النيون السريعة وشريط التشكيل العربي
- **ثيمات النيون الجاهزة:** 🌸 سيبربانك وردي، ⚡ أزرق كهربائي، 🟢 أخضر سام، 👑 ذهبي ملكي، 🔥 برتقالي ناري.
- **شريط الحركات العربية:** أزرار مخصصة لإدراج الحركات فوراً (فتحة، ضمة، كسرة، تنوين، شدة، سكون، تطويل/كشيدة).

### 6. 💾 المشاركة والتصدير
- **حفظ ومشاركة عبر الرابط:** حفظ آلي للحالة بالكامل في الـ URL Hash بتشفير Base64.
- **تصدير كصورة PNG:** تنزيل عالي الدقة 2x جاهز للنشر والطباعة.
- **تصدير كمتجه SVG:** فيكتور قابل للتكبير اللانهائي مع فلاتر التوهج.
- **نسخ كود CSS:** توليد كود جاهز للاستخدام المباشر في مواقع الويب.
- **تسجيل فيديو WebM:** تسجيل مباشر لحركة الكانفاس والمؤثرات وتحميل مقطع فيديو.

## 🚀 التشغيل السريع

### الاستخدام المباشر دون تثبيت
لا حاجة لتثبيت أي حزم أو بناء. يمكنك فتح `index.html` أو `standalone.html` مباشرة في أي متصفح!

### التشغيل عبر خادم محلي
```bash
# استنساخ المستودع
git clone https://github.com/yn1404yn-max/arabic-neon-web.git
cd arabic-neon-web

# تشغيل خادم محلي
python3 -m http.server 8080
```
افتح الرابط: `http://localhost:8080`
